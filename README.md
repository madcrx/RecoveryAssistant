# RecoveryAssistant

## AI-Powered Automated Receivables Collection System

RecoveryAssistant is a world-class, fully automated receivables collection solution that achieves 99% collection rates through intelligent AI-powered communications, seamless payment processing, and proactive dispute prevention.

## Key Features

### 🎯 **99% Collection Rate**
- AI-driven communication strategies optimized for each customer
- Intelligent dunning sequences based on aging and payment history
- Multi-channel engagement (Email, SMS, Self-Service Portal)
- Predictive analytics for collection probability

### 📄 **Intelligent PDF Processing**
- Automatic extraction of aged receivables data from PDF reports
- Supports multiple PDF formats (structured and scanned)
- AI-powered parsing when traditional methods fail
- Instant customer and invoice creation

### 🤖 **AI-Powered Communications**
- Personalized collection messages generated by GPT-4
- Tone adjustment based on customer relationship and invoice aging
- Prevents disputes through clear, empathetic messaging
- Automated follow-ups with optimal timing

### 💳 **Seamless Payment Processing**
- Multiple payment methods (Credit Card, ACH, Wire Transfer)
- Secure payment links sent directly to customers
- Payment plan creation for large invoices
- Automated reconciliation and cash application

### ⚡ **Workflow Automation**
- Intelligent escalation based on aging buckets
- Automated reminder scheduling
- Business rules engine for custom workflows
- Background processing for scalability

### 📊 **Real-Time Analytics**
- Collection effectiveness tracking (CEI)
- Days Sales Outstanding (DSO) monitoring
- Aging distribution visualization
- Payment trend analysis
- Risk-based customer segmentation

### 🛡️ **Dispute Prevention**
- Proactive invoice validation
- Clear payment instructions
- Payment plan options
- Customer self-service portal

## Quick Start

### Prerequisites
- Docker & Docker Compose
- OpenAI API key
- Stripe API key
- SendGrid API key (optional)
- Twilio account (optional)

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/RecoveryAssistant.git
cd RecoveryAssistant
```

### 2. Configure Environment Variables
```bash
# Copy example environment file
cp backend/.env.example backend/.env

# Edit backend/.env with your API keys:
# - OPENAI_API_KEY
# - STRIPE_API_KEY
# - SENDGRID_API_KEY (optional)
# - TWILIO_ACCOUNT_SID (optional)
# - TWILIO_AUTH_TOKEN (optional)
```

### 3. Start the Application
```bash
# Build and start all services
docker-compose up -d

# Check service status
docker-compose ps

# View logs
docker-compose logs -f
```

### 4. Initialize the Database
```bash
# Run database migrations
docker-compose exec backend alembic upgrade head
```

### 5. Access the Application
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Documentation**: http://localhost:8000/docs

## Usage Guide

### Uploading Receivables Reports

1. Navigate to **Upload Report** in the sidebar
2. Click **Select PDF File** and choose your aged receivables PDF
3. Click **Upload and Process**
4. The system will:
   - Extract all invoice data
   - Create/update customer records
   - Trigger automated collection workflows
   - Display summary statistics

### Viewing Dashboard

The dashboard provides real-time insights:
- Total outstanding receivables
- Collection rate (30-day)
- Payments received this month
- Average days to payment
- Aging distribution chart
- High-risk customer count

### Managing Invoices

- View all invoices with filtering options
- See status (Open, Paid, Overdue, Disputed)
- Track aging buckets (Current, 0-30, 31-60, 61-90, 90+)
- Monitor days outstanding

### Managing Customers

- View customer list with risk levels
- Check payment scores
- See outstanding balances
- Update communication preferences

## Workflow Automation

### Collection Workflows

**Standard Reminder Schedule:**
- **0-30 days**: Reminder every 7 days (Friendly tone)
- **31-60 days**: Reminder every 3 days (Professional tone)
- **61-90 days**: Daily reminders (Firm tone)
- **90+ days**: Daily reminders + Escalation (Urgent tone)

**Payment Plan Offers:**
- Automatically offered for invoices > $10,000
- Triggered after 2+ reminders in 31-60 day bucket
- Customizable installment options

**Escalation:**
- Automatic escalation at 90+ days
- Manager notification
- Risk level upgrade
- Legal action preparation

## Troubleshooting

### Common Issues

**PDF Upload Fails:**
- Check file size (< 10MB)
- Ensure PDF is not password protected
- Verify PDF contains extractable text or tables

**Payments Not Processing:**
- Verify Stripe API keys are correct
- Check webhook configuration
- Ensure customer email is valid

**Workflows Not Triggering:**
- Check Celery worker is running: `docker-compose logs celery-worker`
- Verify Redis connection
- Check customer communication preferences
